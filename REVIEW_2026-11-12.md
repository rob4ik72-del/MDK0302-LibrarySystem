# Проверка МДК 03.02 — 12.11.2026

Сверка выполнена с учебным сборником и присланными отчётами Мельника. Чужой вариант, текст, код и измерения не копировались. Дополнительный материал примера отделён от обязательного задания.

| Работа | Проверено и изменено | Сравнение и границы |
|---|---|---|
| ПР1 | Классификация и три обоснованных стандарта; ссылка на репозиторий и снимок приложения. | Восемь характеристик старой модели отделены от девяти характеристик ISO/IEC 25010:2023. |
| ПР2 | Есть сравнение терминов, испытаний и отчётности ГОСТ/ISO, таблица и рекомендации. | Не заявляется формальная эквивалентность разных по предмету стандартов. |
| ПР3 | Есть восемь исходных замечаний, чек-лист, исправленный код и новый протокол Library.Tools из Visual Studio. | У Мельника встроенные анализаторы VS. У нас собственные ограниченные правила Roslyn, не полный SAST. |
| ПР4 | Есть CC, MI, LOC, LCOM1, сравнение до/после и новый снимок вывода. | Coupling — синтаксическая AST-оценка, а не семантический CBO Visual Studio. Это ограничение сохранено явно. |
| ПР5 | Есть профиль восьми характеристик, кейс Zip Slip и план мер. | У Мельника другой кейс с нагрузкой; его измерения нельзя переносить в Library System. |
| ПР6 | Есть тест-кейсы, баг-репорты Critical/Major/Minor, покрытие требований, xUnit/FluentAssertions и снимок Test Explorer 47/47. | 47 случаев xUnit и 12 HTTP-сценариев пересекаются; число 59 независимых тестов не заявляется. |
| Эссе | Есть введение, смысловые разделы, заключение, источники и обсуждение legacy-адаптеров. | Эссе не требует отдельного снимка программы. |
| ПР7 | Есть DFD, шесть STRIDE-категорий, OWASP и эшелоны защиты. | Учебный loopback HTTP не выдаётся за промышленный защищённый транспорт. |
| ПР8 | Есть before/after, FluentValidation, EF Core, policy, rate limit, интеграционные тесты и DevTools 201/Quarantined/403. | Отдельной ПР8 в присланном комплекте Мельника нет; сверка выполнена по заданию. Токены удалены из встроенных кадров. |

- Задания преподавателя МДК 03.01 ПР1–8, МДК 03.02 ПР1–8 и эссе, МДК 02.02 ПР1–9.
- Материалы Мельника, предоставленные пользователем (15 документов по 03.01, 8 по 03.02, 9 по 02.02).
- Исходники, документы, исходные журналы и снимки Windows пользователя.
