# МДК 03.02 — Library System
Шваб Роберт Эдуардович, И13_24_11. Вариант 2: электронная библиотека PDF/EPUB.

## Запуск
Требуются Windows 10/11, .NET 8 SDK, браузер и доступ к nuget.org для первого восстановления.
Visual Studio 2022 открывает LibrarySystem.sln. Программы написаны на C# 12 и .NET 8.
Распаковать архив целиком. Запустить Build.cmd, затем Run_Tests.cmd.
Для интерфейса выбрать Run_PR01.cmd ... Run_PR08.cmd. Открывается нужный раздел после старта API.
Один экземпляр API обслуживает все работы. Адрес http://127.0.0.1:5352 . Остановка — Ctrl+C.
Если вкладка не открылась автоматически, ввести адрес вручную после Now listening.

| Работа | Программа | Результат |
|---|---|---|
| ПР 1 | Run_PR01.cmd | Матрица стандартов JSON/CSV |
| ПР 2 | Run_PR02.cmd | Гармонизация JSON/CSV |
| ПР 3 | Run_PR03.cmd | Статический аудит Roslyn |
| ПР 4 | Run_PR04.cmd | CC, MI, AST-зависимости, LCOM1 |
| ПР 5 | Run_PR05.cmd | Матрица и радар качества |

| ПР 7 | Run_PR07.cmd | STRIDE и DFD |
| ПР 8 | Run_PR08.cmd | Защищённая загрузка и 12 HTTP-сценариев |

## Проверка вручную
Раздел Библиотека: выбрать Librarian, скачать собственный образец PDF по ссылке,
выбрать его в форме и нажать Загрузить книгу. Ожидается 201, Quarantined.
С ролью Reader повторить: 403. Новые файлы остаются в приватном карантине.
ПР 8 → Выполнить проверки API: 12 сценариев обращаются к настоящему работающему API.
ПР 6 показывает разбор сохранённого TRX; Run_Tests.cmd обновляет его.
47 случаев xUnit и 12 HTTP-сценариев пересекаются и не складываются в число независимых тестов.

## Структура и границы
Core — правила файлов; Api — сервер, контроллеры, FluentValidation, EF Core SQLite;
Tools — обработка матриц, Roslyn-анализатор, разбор TRX; tests — xUnit и FluentAssertions 6.12.2.
before — намеренно уязвимый исходный образец, не включён в сборку и HTTP-маршруты.
docs — ТЗ, методика испытаний, схема, листинги в отчётах и настоящие снимки браузерного интерфейса.
App_Data, bin, obj, .vs не добавляются в Git. Данные и токены пользователей не публикуются.
Учебная выдача ролей разрешена только в Development с loopback. Для внешнего размещения нужны
внешний IdP, HTTPS, AV/CDR и согласованная процедура публикации. Проверка сигнатуры не заменяет антивирус.
verification содержит исходные результаты, а не вручную набранные сообщения об успехе.
