## Как снять реальные HTTP-запросы

1. Назначьте Library.Api запускаемым проектом, выберите профиль Library.Api, нажмите Ctrl+F5. Браузер откроется на http://127.0.0.1:5352. API запускается из Visual Studio.
2. Откройте «Библиотека и загрузка». Нажмите F12 → Network, включите Preserve log. Введите фильтр `/api/books/upload`.
3. Выберите Librarian. Скачайте образец PDF по ссылке приложения, выберите его в форме и нажмите «Загрузить книгу». В Network выберите POST `/api/books/upload`. Снимите Headers: метод, URL и Status Code 201; Payload: title и file; Response: результат загрузки и статус карантина.
4. Переключитесь на Reader и повторите загрузку: снимите POST и ответ 403. Учебная сессия переключается приложением.
5. Выберите Librarian, скачайте образец Zip Slip и загрузите его: снимите ответ 400. При частых повторах возможен 429; дождитесь следующей минуты перед другим независимым сценарием.
6. На снимках оставляйте название приложения, запрос и читаемый ответ. Скрывайте значение Authorization, Cookie и токены: они не нужны для отчёта. Делайте снимки Win+Shift+S.

Кнопка «Выполнить проверки API» в ПР 8 вызывает `/lab/scenarios`. Это серверные проверки; их таблица не заменяет браузерный POST `/api/books/upload` в DevTools.

47 случаев xUnit и 12 HTTP-сценариев частично проверяют одно и то же: их нельзя складывать как независимые тесты. Новые снимки из Windows нужно вставить в отчёты после фактического выполнения.
