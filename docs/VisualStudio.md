# Показ работ в Visual Studio

1. Откройте `LibrarySystem.sln` в Visual Studio 2022.
2. В обозревателе решений раскройте `src`. Щёлкните правой кнопкой по `Library.Desktop` и назначьте его запускаемым проектом.
3. Нажмите F5. Дождитесь окна «Электронная библиотека — МДК 03.02».
4. Перейдите на вкладку нужной работы. Снимок Windows можно сделать через Win+Shift+S. Если преподаватель просит видеть среду, оставьте в кадре окно Visual Studio и окно программы.

| Работа | Что показать |
| --- | --- |
| ПР 1 | Вкладка со сводной матрицей стандартов. |
| ПР 2 | Вкладка сравнения ГОСТ и ISO/IEC. |
| ПР 3 | Найденные при аудите несоответствия. |
| ПР 4 | Сравнение метрик до и после рефакторинга. |
| ПР 5 | Матрица характеристик качества. |
| ПР 6 | Для снимка нового прогона: «Тест → Обозреватель тестов → Запустить все». Вкладка в приложении показывает сохранённый результат, а не новый запуск. |
| ПР 7 | Матрица STRIDE, если нужен показ программы. DFD находится в отчёте и в `docs/diagrams/DFD.svg`. |
| ПР 8 | Вкладка «ПР 8»: нажмите «Выполнить проверки API» и снимите итог фактического прогона. Для снимка xUnit используйте обозреватель тестов. |

Если Visual Studio сообщает, что не может восстановить зависимости, проверьте доступ к NuGet и установленный .NET 8 SDK. Если приложение сообщает, что не найден WebView2 Runtime, установите [Evergreen Runtime Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/).

[Справка Microsoft: запуск тестов в Visual Studio](https://learn.microsoft.com/en-us/visualstudio/test/walkthrough-creating-and-running-unit-tests-for-managed-code)

## Проверка перед сдачей

- В обозревателе решений виден запускаемый проект `Library.Desktop`. Нажатие F5 открывает окно программы без ручного запуска API. При проверке разместите окно приложения рядом с Visual Studio или уменьшите его так, чтобы были видны и приложение, и название решения в Visual Studio.
- Пройдите вкладки ПР 1–8. Для ПР 1–5 убедитесь, что в таблицах есть строки. В ПР 7 проверьте схему под таблицей STRIDE. Снимок ПР 7 нужен только по просьбе преподавателя; схема уже есть в отчёте. Для эссе снимок не нужен.
- ПР 6 снимите в обозревателе тестов после команды «Запустить все». В кадре должны читаться итоговые счётчики. Сохранённый результат во вкладке приложения не заменяет этот снимок.
- ПР 8 снимите после нажатия «Выполнить проверки API». В кадре должны читаться итог и строки, например Zip Slip, запрет записи для Reader и ограничение частоты.
- Закройте окно и нажмите F5 ещё раз, чтобы проверить повторный запуск. Для снимков используйте Win+Shift+S; сохраняйте под именами PR01.png — PR08.png. Если сборка падает, сохраните вместо отчётного снимка первую ошибку из списка ошибок.

WebView2 показывает учебные страницы внутри окна WinForms. Для работы в Visual Studio отдельный браузер не открывается.
