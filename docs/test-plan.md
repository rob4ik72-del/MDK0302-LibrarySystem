# Программа и методика испытаний LS-TP-01
Объект: Library System, вариант 2. Дата 08.11.2026.
Основание: LS-TZ-01; ГОСТ 19.301-79; структура отчёта ISO/IEC/IEEE 29119-3:2021.
Условия: .NET 8 SDK, восстановленные NuGet-пакеты, успешная сборка.
Данные: собственные PDF/EPUB и сформированные ZIP; реальные пользовательские книги не требуются.
Модульный уровень: FilePolicy и анализатор Roslyn. Интеграционный: WebApplicationFactory,
настоящая SQLite и отдельный временный каталог каждого ApiHarness. Сквозной: Kestrel и HttpClient.
Порядок: Build.cmd → Run_Tests.cmd → Run_PR08.cmd → Выполнить проверки API.
Позитивные: PDF, EPUB, две книги в ZIP. Негативные: пути, ссылки, EXE, подмена PDF, права, токен.
Границы: 0 байт — 400; 1 МиБ — 201; 1 МиБ+1 — 413; 12 записей допустимы, 13 — отказ;
четвёртая загрузка за минуту — 429. Дополнительно проверены ZIP-бомба и фактический предел чтения.
Критерий завершения: нет Failed / Skipped, статусы соответствуют ожидаемым,
после отклонённого ZIP нет сохранённых книг. Результат: 47 Passed / 0 Failed / 0 Skipped.
Матрица traceability.json отражает покрытие требований, не процент покрытия строк кода.
Точная транспортная граница multipart, восстановление после питания и реальная многопользовательская нагрузка не измерялись.
Проверка сигнатуры PDF не является антивирусом. Новые файлы не выдаются из карантина.
Исходный before исследован статически, в HTTP-приложение не включён.
