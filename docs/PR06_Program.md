# ПР 6 — Тестирование

Открыть `LibrarySystem.sln`, выбрать запускаемым проектом `Library.Desktop` и нажать F5. В окне приложения выбрать вкладку ПР 6.

Для нового прогона открыть «Тест → Обозреватель тестов» и запустить все тесты. Вкладка показывает сохранённый итог.
